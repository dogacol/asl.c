# Sample style prompts

Use these with `--style` to steer the rough-cut character.

| Prompt | Effect |
|---|---|
| `poetic observational montage` | Slow, contemplative, favours wide shots and ambient sound |
| `dialogue-first interview rough cut` | Prioritises spoken content, stable medium shots |
| `experimental associative edit` | Non-linear, juxtaposes unrelated segments by mood |
| `trailer-like` | High energy, short clips, builds to a peak |
| `action-first` | Favours motion, dynamic framing, fast cuts |
| `mood piece` | Emotional arc, quiet moments, visual texture |
